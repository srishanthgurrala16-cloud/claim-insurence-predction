EXPLORATORY DATA ANALYSIS

Analysis Areas

Overview of the exploratory data analysis domains used in the machine learning workflow.

DATA DISTRIBUTION

Used to analyze frequency histograms, skewness, and variance across continuous features (cont1 to cont14) and categorical variables (cat1 to cat116) to verify data normality and scaling requirements.

FEATURE RELATIONSHIPS

Used to evaluate pairwise feature correlation matrices, detect multicollinearity among continuous predictors, and identify high-leverage feature interaction pairs.

CATEGORICAL ANALYSIS

Used to inspect high-cardinality categorical feature distributions, frequency encoding boundaries, and variance across policy, claim, and customer risk categories.

TARGET VARIABLE

Used to examine the target variable loss, its probability density distribution, logarithmic transformations, and extreme loss tail characteristics.

MODEL PERFORMANCE

Used to evaluate post-training regression outputs through residual scatter plots, predicted vs. actual claim loss comparisons, and error metric distributions.

Analytical Role: Exploratory visualization is an essential diagnostic stage in the machine learning workflow. It enables data scientists to validate data quality prior to regression model training.
