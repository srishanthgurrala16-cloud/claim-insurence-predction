About ClaimWise Insurance Prediction System

Project Introduction

ClaimWise Insurance Prediction System is a machine learning project designed to analyze insurance claim data and predict claim loss.

Objectives

  • Analyze insurance claim data.
  • Clean and preprocess the dataset.
  • Handle missing values.
  • Encode categorical features.
  • Scale numerical features.
  • Prepare data for machine learning.
  • Predict insurance claim loss.
  • Understand factors affecting claim loss.

Technologies Used

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • Matplotlib
  • Seaborn
  • HTML
  • CSS
  • Machine Learning
