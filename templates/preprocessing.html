Data Preprocessing Workflow

1. Dataset Loading

Read raw claim dataset (50,000 records × 132 features) and perform structural data audit.

2. Duplicate Removal

Identify and drop duplicate rows to preserve data integrity across the dataset.

3. Missing Value Handling

Missing numerical values are handled using median imputation and categorical values using mode imputation.

4. Numerical Feature Imputation

Replace missing continuous values (cont1–cont14) with median values.

5. Categorical Feature Imputation

Clean text whitespace and replace missing categorical values (cat1–cat116) with mode values.

6. Categorical Encoding

Apply LabelEncoder to convert categorical text features into integer numerical representations.

7. Feature Scaling

Standardize continuous numerical attributes using StandardScaler fit on training features.

8. Target Separation

Separate target column 'loss' from input feature matrix X.

9. Train-Test Split

Split preprocessed dataset into 80% Training (40,000) and 20% Testing (10,000) subsets.
